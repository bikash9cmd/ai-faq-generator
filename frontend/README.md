# AI FAQ Generator — Frontend

React 19 + Vite user interface for the [AI FAQ Generator](../README.md).

```bash
npm install
npm run dev      # start the dev server on http://localhost:5173
npm run build    # production build in dist/
npm run lint     # lint with oxlint
```

The app talks to the FastAPI backend at `http://127.0.0.1:8000` (set in `src/App.jsx`), so start the backend first.
